# ditherzam map context

One job: route a cold agent to the smallest source-backed context for a safe change.

- `live`: wired now; implement and cite here.
- `leftover`: present but not the primary path; touch only when in scope.
- `ghost`: planned or stubbed, not wired; never call it shipped.

The public release and original development histories are distinct. Read memory
before branch, release, native-code, or packaging work.

## Walk

1. Route through objects or processes.
2. Check effects before editing.
3. Follow cited paths into current source and tests.
4. Record durable changes through zam-memory.

## Human check

A proposed change must reach authoritative source within three reads and identify
both its first-order hits and an obvious non-hit.
