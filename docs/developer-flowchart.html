01Process bootstrap and dependency boundaryditherzam.app:main() → QApplication → ImageEditor → app.exec()＋

Python / package

CPython 3.12 only. Setuptools exposes console script ditherzam = ditherzam.app:main. Required libraries: NumPy, Numba, Pillow, PyYAML, platformdirs, PySide6. Release extras: ONNX Runtime and PyInstaller.

Qt isolation

Only ui/, app.py, and video/workers.py may import PySide6. Render, color, mask geometry, ffmpeg command construction, export, and animation math remain headless and testable.

Startup sequence

Create/reuse QApplication, apply Fusion + YAML theme, attempt local Smart Mask adapter construction, instantiate ImageEditor, install measured Numba thread budget, then start background kernel warm-up.

Optional components

ONNX Runtime loads only if a locally staged, validated model exists. ffmpeg is resolved when video operations run. Neither is downloaded by the app; absence becomes a disabled feature or explicit error.

--offline-smoke is a separate non-GUI entry path used to validate a frozen release lock and staged Smart Mask assets.

Gray conversion

Pillow images use convert("L"). Generic 3-D arrays use the arithmetic mean of their first three channels in to_gray_f32.

Atomic publication

All types, shapes, ranges, and RGB/RGBA agreement are checked before editor fields change. Then old inference/caches are invalidated and the three new arrays become one source generation.

Ownership

Public callers are defensively copied for RGBA. Only a private decoder-owned, immutable, contiguous buffer may transfer ownership without another copy.

03Mutable GUI state becomes an immutable render requestcontrols/state dict → RenderSettings + context snapshots → RenderRequest(frozen=True)＋

GUI authority

ControlPanel.state holds style, scale, tonal settings, dither parameters, palette/color mode/depth, saturation, invert, and effect descriptions. Glow and Smart Mask panels hold their own typed state.

Context rebuild

_sync_pipeline() derives a new ColorEngine and ordered EffectStack. Color engines act immutably; editor-owned ColorContextCache reuses palette-derived ramp data.

Frozen request

RenderRequest captures settings, source reference/identity, logical geometry, target pixel cap, color engine, effect stack, mask context, overlay flag, kind, and generation. A worker never rereads live controls.

Reason

Snapshotting prevents a GUI-thread reassignment from mixing old color state with new effects, and makes cancellation/cache identities deterministic.

04Preview scheduler controls concurrency and qualityQTimer debounce + Qt-free RenderScheduler + QThreadPool QRunnable＋
edit→ 20 msDRAG ≤ min(640, cap)→ 160 ms idleSETTLE ≤ cap→ workerstage-boundary cancellation

One + one policy

There is at most one running preview and one pending trailing request. Busy-time edits replace the pending request using generation and priority, preventing a slider drag from spawning an unbounded worker queue.

Priority

Within a generation: DRAG < SETTLE = ZOOM < FULL; equal priority keeps the newest. A newer generation always supersedes an older one.

Pixel policy

Auto cap derives from source shape, viewport pixels, and device-pixel ratio. Fixed caps and optional zoom buckets are clamped to the source. Explicit Full Quality Preview is uncapped.

Terminal discipline

Success, cancellation, and failure all call on_finished(). Only a current generation paints. Every terminal path releases busy and launches the freshest trailing request, avoiding scheduler wedges.

Numba kernels may run parallel internally; the preview layer still launches only one render worker at once. Cancellation never interrupts a kernel mid-buffer—it is checked between complete pipeline stages.
05L1 tonal math on grayscale float32RenderPipeline.render[_cached] · contrast → midtones → highlights → blur＋
Input g ∈ float32[H,W], nominal range [0,255] contrast: g₁ = g × (C / 50) gamma: γ = max(1 + (M − 50)/200, 0.1) midtones: g₂ = 255 × (g₁/255)^(1/γ) highlights: g₃ = g₂ × (1 + (H − 50)/100) blur: radius = (B/10)²; Pillow GaussianBlur(clamp_u8(g₃), radius)

Scratch reuse

Contrast, midtones, and highlights target a single call-private NumPy buffer via ufunc out=. It is never global and never reused across concurrent calls.

Staged cache L1

Key material includes source identity/content key and adjustment signature. Blur returns its input when radius ≤ 0. A changed earlier stage dirties every later cached stage.

Clamping

Intermediate tonal values may leave 0…255. clamp_u8 clips only at Pillow boundaries or final conversion, preserving float calculations between stages.

06L2 dither dispatch and kernel mathematicsapply_dither() → scale grid → temporal/creative transforms → registry kernel → levels → upscale＋
nearest downscale by s→g − temporal_field→rotate/roll/jitter→kernel(small,param,t,levels)→mix + nearest upscale

Kernel ABI

Registry entries point to Numba @njit(cache=True[, parallel=True]) functions. Inputs are float32 image, style-native parameter(s), threshold byte t = luminance_threshold/100 × 255, and optionally levels.

Families

Error diffusion propagates quantization error to future pixels; ordered/Bayer compares against a periodic threshold matrix; pattern and special kernels generate spatial fields; glitch/generative families use deterministic coordinate math and seeded hashes.

Scale semantics

Pillow nearest-neighbor downsamples to (⌊W/s⌋,⌊H/s⌋). Dither runs on that pixel grid, then nearest-neighbor expands back to the input geometry, producing block size without smoothing.

Temporal field

A float threshold field is nearest-resized to the small grid and subtracted from intensity: comparing g − f to t is equivalent to comparing g to spatial threshold t + f.

Binary-kernel promotion when levels L > 2: Δ = 255/(L−1); q = clip(g,0,255)/Δ; base = floor(q); fraction = q−base bit = kernel(255×fraction) ≥ 128 output = clip((base + bit)×Δ, 0, 255) Canonical Floyd–Steinberg error e = old − quantized: right += 7e/16; down-left += 3e/16; down += 5e/16; down-right += e/16
Default creative settings return the original objects and historical pixels. Jitter uses a deterministic uint32 coordinate hash; mix computes original×(1−α) + styled×α.
07L3 color engine maps tone to RGBColorEngine.map() · off / nearest / ordered / diffusion / ramp / source＋

Nearest palette

For each pixel x, select the first palette index minimizing squared RGB distance: argminᵢ [(r−rᵢ)²+(g−gᵢ)²+(b−bᵢ)²]. Numba loops avoid an H×W×K×3 temporary.

Ordered RGB

A recursively constructed 4×4 Bayer value in [−0.5,0.5) is multiplied by 255/(K−1), added to all channels, and fed directly to nearest palette search in one fused Numba pass.

RGB diffusion

Sequential Numba Floyd–Steinberg chooses nearest palette color, computes a three-channel error vector, and distributes it with 7/16, 3/16, 5/16, 1/16 weights.

Depth ramp

Compute Rec.601 luminance Y=.299R+.587G+.114B, then i=clip(round(Y/255×(D−1)),0,D−1) and output ramp[i]. Grayscale skips synthetic RGB/luminance work.

Source Colors

Resize original RGB by nearest sampling, simplify it to palette colors, then modulate those local hues by dither luminance. The option can multiply toward black or screen toward white, blended by the Colored Dither influence.

Context cache

Palette colors/ramp are keyed by palette, mode, depth, mapping, and phase. Cached arrays are read-only; engines are derived with with_settings() instead of mutating shared render context.

08L4–L6 finishing math and effectssaturation → ordered EffectStack → invert last → uint8/RGB＋
Rec.601 luminance: Y = 0.299R + 0.587G + 0.114B saturation factor: f = S/50 each channel: c′ = clip(Y + (c−Y)×f, 0, 255) invert (last): c″ = 255 − c′

Saturation

Parallel Numba emits final RGB uint8 directly. S=50 is identity, S=0 is grayscale, and S=100 doubles chroma distance from luminance.

EffectStack

An ordered list of (name, params) dispatches left-to-right: Pillow Gaussian blur, unsharp-like sharpen, NumPy red/blue channel rolls, in-memory JPEG encode/decode glitch, or Epsilon Glow.

Epsilon Glow

Soft threshold t²(3−2t) selects bright Rec.601 pixels; three anisotropic Gaussian scales (0.5r, r, 2r) are weighted and combined; an epsilon-powered tight core is added; result is clipped.

Invert / cache

Invert is intentionally after all effects and recomputed each call. It uses a private float32 buffer, clips in-place, then allocates uint8. Earlier color/saturation/effect results may be retained in the bounded render cache.

09Optional ONNX inference and deterministic mask geometryimmutable RGBA → adapter → probability float32 → threshold/morphology/feather＋

Inference thread

A dedicated single-thread QThreadPool owns mask inference work. InferenceRequest freezes source/model/preprocessing identity. Scheduler coalescing and cancellation prevent results from attaching to a replacement source.

ONNX adapter

The optional onnxruntime.InferenceSession preprocesses source input to the model tensor, runs locally, validates output, restores source geometry, and publishes an immutable confidence array in [0,1].

Threshold

Sensitivity maps to inclusive confidence threshold T=(100−sensitivity)/100. Subject is P≥T; Background is 1−Subject; optional invert is applied next.

Morphology

Expansion uses separable rolling counts with uint32 cumulative sums: positive radius is square max-filter dilation; negative radius is square min-filter erosion. Complexity is O(HW), not O(HW·r²).

Feather/resize

Quantize mask to a byte image, apply Pillow Gaussian blur with source-pixel radius, divide by 255, and freeze float32. Preview resize uses BOX area sampling to preserve fractional coverage.

Identity

Derived-mask cache keys include probability identity, sensitivity, target, invert, expansion, feather, and algorithm version. Missing/unlicensed model assets disable inference rather than silently using another path.

10Mask wraps the complete render branchbypass OR pre-dither bake OR post-render straight-alpha composite＋

Byte-exact bypass

If no mask context exists, render_with_mask calls the historical renderer immediately—no hashing, mask allocation, geometry, resizing, or compositing.

Baked fill

For White/Black + bake: baked = base×m + fill×(1−m). This happens before preview resize and L1, so dithering/effects texture the fill. It uses uncached pipeline.render because staged keys do not encode the baked base.

Outer composite

Otherwise render all nine stages first. Resize source RGBA by nearest and mask by BOX; combine processed inside with Original/Transparent/White/Black outside using compiled straight-alpha byte math.

Alpha equation

Coverage byte c=floor(255m+0.5); outside weight q=255−c; A=(255c+qAₒ+127)//255. RGB contributions combine premultiplied, then divide back to straight RGB with nearest/ties-up rounding.

Composite caching includes rendered identity, target geometry, mask identity, outside mode, source identity, alpha algorithm version, and whether the branch was baked.
11Cross the NumPy–Qt display boundary safelyuint8 ndarray → owned QImage → QPixmap → source-logical QGraphicsView＋

Ownership

numpy_to_qimage creates a QImage with safe lifetime rather than borrowing a temporary NumPy buffer. A prior zero-copy approach was rejected because safe ownership variants were slower and unsafe borrowing could dangle.

Latest paint

The queued worker signal carries image + frozen request. GUI thread paints only if scheduler.is_current(request); stale completion is dropped.

Geometry

The pixmap may be capped, but its scene rectangle uses original source logical width/height. The first image paint fits the view; later previews preserve transform, pan, and zoom.

Recovery

Rendered, cancelled, and failed signals all advance the scheduler. Exceptions are logged and do not paint; a pending newest request still launches.

Subprocess safety

ffmpeg/ffprobe commands are built as argument lists, not shell strings. Core command builders are pure/injectable; subprocess execution raises typed errors with captured output.

Preview vs export

Animation/video screen playback is capped for responsiveness. Export generators never consult the screen cap and always use exact output context.

Worker lifetime

Video and animation controllers retain QRunnable/signal objects until terminal delivery; otherwise QThreadPool auto-delete can destroy signal owners before queued completion reaches the GUI.
