ditherzam is a clean-room open-source build. Never copy, embed, or ship any Dither
Boy / Studio AAA source code, verbatim strings, URLs, or licensing endpoints, and
never commit their binaries/installer/patcher (`.gitignore` blocks `*.exe`,
`Dither-Boy-*/`, `DBPatcher/`). Public-domain algorithm *techniques*
(Floyd–Steinberg, Atkinson, Bayer, median-cut, etc.) are fine to implement from
public sources. No licensing/telemetry/network code of any kind. See [[004-key-references]].
