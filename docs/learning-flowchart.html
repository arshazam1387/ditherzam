1Python builds the applicationEntry point → PySide6 → event loop＋
Plain English: Python enters one starting function, creates the window system and ditherzam window, then waits for user actions.

Entry point

An entry point is the program’s agreed starting door. Here it is ditherzam.app:main.

Library / dependency

A library is reusable code from elsewhere. A dependency is a library the project requires.

PySide6 and Qt

Qt supplies windows, controls, timers, images, and threads. PySide6 lets Python use Qt.

Event loop

The event loop waits for clicks, drags, timers, and signals, then calls the connected handler.

The GUI thread should react quickly; expensive pixel calculations run elsewhere.
↓
2The image becomes numbersPillow file decoding → NumPy arrays＋
Plain English: PNG/JPEG bytes are decoded by Pillow. NumPy stores the pixels as rectangular grids of numbers.

Array

An array is a same-type grid. Gray shape is [height,width]; RGB is [height,width,3].

dtype

dtype describes number storage. uint8 holds integers 0–255; float32 holds fractions for math.

Channel

A channel is one component per pixel: red, green, blue, and optional alpha opacity.

Immutable

Immutable means not changeable. Source RGBA is read-only so workers see stable data.

gray float32 [H,W] → render math RGB uint8 [H,W,3] → original color RGBA uint8 [H,W,4] → color + transparency
After decoding, the program works mainly with typed NumPy arrays—not the original file format.
↓
3Changing controls become one stable requestMutable state → immutable snapshot＋
Plain English: Sliders can change during a render. ditherzam photographs all settings first so one worker sees one consistent moment.

State

State is everything describing the app now: source, sliders, palette, effects, mask, and preview quality.

Snapshot

A snapshot is a fixed view of state. RenderRequest captures all inputs before work starts.

Dataclass

A dataclass is a Python class designed to hold named data. frozen=True prevents reassignment.

Race condition

A race condition is a timing bug. Without snapshots, a worker could combine an old palette with new effects.

A render request represents one coherent version of the document.
↓
4The scheduler avoids obsolete workDebounce → coalesce → worker thread → newest result＋
Plain English: A slider can fire dozens of changes. Rendering all of them would create a traffic jam, so the scheduler keeps one running job and one freshest waiting job.

Thread

A thread is one path of execution. The GUI thread handles widgets; a worker thread calculates pixels.

Debounce

Debouncing waits briefly for repeated input. Drag preview starts after 20 ms; settled preview after 160 ms idle.

Coalescing

Coalescing replaces many waiting jobs with one useful latest request.

Generation

A generation is a version number. Only a result matching the current generation may paint.

Cancellation

Cancellation stops obsolete work at safe boundaries between complete render stages.

Proxy

A proxy is a smaller temporary render for speed. Exact exports never use the screen-size cap.

The app stays responsive mainly by refusing to finish work the user no longer needs.
↓
5Tonal math prepares brightnessContrast → gamma → highlights → Gaussian blur＋
Plain English: Before creating a pattern, ditherzam reshapes grayscale brightness so the later dither emphasizes the intended regions.

Contrast

A straight multiplier: g′=g×(value/50). Value 50 is unchanged.

Gamma

Gamma is curved brightness math: 255×(g/255)^(1/γ). It changes midtones more than endpoints.

Gaussian blur

A Gaussian blur replaces each pixel with a weighted neighborhood average, favoring nearby pixels.

Buffer

A buffer is memory for intermediate values. NumPy out= safely reuses one private buffer.

Tonal stages prepare intensity; they do not choose the final pattern or color.
↓
6Dithering creates apparent shadesQuantization + spatial pattern or error movement＋
Plain English: Dithering imitates missing shades by arranging available shades. Your eye averages nearby dots into an apparent intermediate tone.

Quantization

Quantization maps many possible values to a smaller set, such as 256 gray values into black and white.

Threshold

A threshold is a dividing value: below becomes one result, above becomes another.

Kernel

Here a kernel is the function implementing one dither style. A registry maps names to kernels.

Ordered dither

Ordered dithering repeats a small matrix of different thresholds across the image.

Error diffusion

Error diffusion rounds a pixel, measures the error, and gives weighted pieces to future neighbors.

Nearest-neighbor

Nearest-neighbor resize copies the closest pixel without blending, preserving crisp blocks.

Numba / JIT

Numba compiles numeric Python. JIT means machine code is created when first needed and cached.

Parallel

Independent rows may use CPU threads. Error diffusion stays sequential because later pixels depend on earlier errors.

Floyd–Steinberg: error = old − chosen right += 7/16 error; down-left += 3/16 down += 5/16; down-right += 1/16
Dither is controlled rounding: the algorithm decides where threshold variation or rounding error goes.
↓
7The color engine chooses RGB valuesPalette distance, luminance, Bayer bias, ramp, or diffusion＋
Plain English: Dither creates tone structure. The color engine decides which actual palette colors display that structure.

Palette

A palette is a limited list of allowed colors.

Color distance

Closest color minimizes (R−Rᵢ)²+(G−Gᵢ)²+(B−Bᵢ)². No square root is needed to find the winner.

Luminance

Luminance estimates perceived brightness: Y=.299R+.587G+.114B.

Bayer matrix

A Bayer matrix is a small evenly distributed threshold grid repeated across an image.

Ramp

A ramp orders colors dark-to-light. Luminance chooses a depth position.

Cache

A cache stores computed work and reuses it only when every important input still matches.

Dither chooses spatial texture; the color engine chooses the RGB values that represent it.
↓
8Effects finish the imageSaturation → effect stack → invert → clipping＋
Plain English: After color mapping, ditherzam adjusts colorfulness, runs each effect in order, optionally inverts the whole result, and produces displayable bytes.

Saturation

Saturation is colorfulness. Channels move toward/away from luminance: Y+(channel−Y)×factor.

Stack

A stack is an ordered sequence. Every effect receives the previous effect’s output, so order changes pixels.

Clipping

Clipping restricts values to 0–255 before conversion to uint8.

Invert

Invert computes 255−value and happens last, after every effect.

Pipeline order is part of the visual algorithm.
↓
9Smart Mask selects a regionONNX inference → probabilities → morphology → feather＋
Plain English: A machine-learning model estimates which pixels belong to the subject. Regular image math turns that estimate into an editable selector.

Model / inference

A model is learned parameters plus a computation graph. Inference runs new input through it.

ONNX

ONNX is a portable model format. ONNX Runtime executes it locally.

Probability map

A float32 [H,W] grid from 0–1; higher values mean more confidence that a pixel is subject.

Mask

A mask is a selector image: 1 is processed, 0 is outside, fractions blend.

Morphology

Dilation expands a selection; erosion contracts it.

Feather

Feathering Gaussian-blurs the boundary to create a soft blend.

The model supplies probabilities; ordinary settings and geometry produce the final mask.
↓
10Compositing mixes selected regionsRendered image + outside image + mask coverage＋
Plain English: At each pixel, the mask acts like a mixing dial between the processed image and the chosen outside content.

Composite

To composite means combine layers: inside×mask + outside×(1−mask).

Alpha

Alpha is opacity. Straight-alpha RGB is temporarily combined in premultiplied form to avoid dark edge fringes.

Baked fill

Baking changes the input before rendering, so dither and effects also process the white/black outside.

Algorithm version

A cache key includes an algorithm version so results from changed math are not confused with old ones.

Outer compositing mixes finished images; baking changes what enters the pipeline.
↓
11The result returns to QtNumPy → QImage → QPixmap → viewport＋
Plain English: The worker returns an array. Qt receives a safely owned image, confirms it is current, and displays it.

QImage / QPixmap

QImage stores image data; QPixmap is optimized for screen display.

Ownership

Ownership decides who keeps memory alive. Qt must not borrow a temporary array that can disappear.

Signal / slot

A Qt signal announces data; a slot is the connected handler. Queued signals cross threads safely.

Logical geometry

A small preview is displayed inside the full source coordinate rectangle, preserving meaningful zoom and pan.

Workers calculate pixels; the GUI thread owns widget painting.
↓
12Export makes a permanent fileExact rerender → encoder → optional ffmpeg subprocess＋
Plain English: The screen preview may be small. Export reruns the pipeline exactly, then converts pixels or frames into the selected file format.

Encoding

Encoding turns raw pixels/frames into PNG, JPEG, SVG, or video.

Subprocess

A subprocess is another program launched by ditherzam. ffmpeg and ffprobe run this way.

ffprobe / ffmpeg

ffprobe reads media facts; ffmpeg extracts frames, encodes video, and combines streams.

Mux

To mux means package processed video and audio streams into one container.

Serialization

Serialization turns state into stored data. Presets store settings as YAML, not pixels.

Exact render

Exact export ignores the screen preview cap and uses the requested source/output resolution.

Preview optimizes interaction; export optimizes correctness.
