01Launch & establish the runtimeQt shell, theme, optional offline model, thread budget, JIT warm-up＋
python -m ditherzam.app→QApplication + Fusion→ImageEditor→event loop

Theme

Find themes/default/theme.yaml; if present, parse it and apply its stylesheet to the application.

Smart Mask startup

Look only for a locally staged ONNX model. If validation/loading fails or no asset exists, return None and keep Smart Mask disabled. There is no network fetch.

Editor construction

Create the registry-backed render pipeline, bounded render/mask caches, viewport, Editor and Glow tabs, menus, timers, render scheduler, mask inference scheduler, and worker pools.

Performance setup

Install the measured interactive Numba thread budget, then warm common JIT kernels on a background thread so the GUI can remain responsive.

Special CLI branch: --offline-smoke bypasses the GUI and verifies a frozen Smart Mask release lock.
02Acquire & normalize source mediaStill image or decoded video frames become validated NumPy source authority＋

Still image

Drag/drop or load a file. A decode worker produces grayscale float32 H×W, RGB uint8 H×W×3, and immutable RGBA uint8 H×W×4.

Validation

Reject wrong types, dimensions, non-finite gray values, out-of-range values, shape mismatches, or RGBA whose RGB channels disagree with the RGB source.

Atomic replacement

Validate everything first; then invalidate old mask inference, clear old source mask/render caches, publish all source arrays together, reset mask UI, and mark the next paint to fit the viewport.

Video import

Probe FPS/duration/audio, enforce ordinary 60 fps / 60 s limits, extract frames with ffmpeg into a temporary directory, and load a representative preview frame. Expert mode can bypass the duration/FPS cap.

The pipeline processes grayscale as its base. Original RGB feeds “Source Colors” behavior; immutable RGBA is retained for alpha-safe Smart Mask compositing.

Tonal & color controls

Effects

Preview & motion

Presets serialize render settings, palette/effect state, and Smart Mask settings. Loading applies state as one operation, then renders; legacy presets receive safe defaults.
04Optional Smart Mask lifecycleWhole image bypass, or asynchronous subject/background probability detection＋
mask disabled / Whole Image→ historical byte-exact bypassmask enabled + Subject/Background→ inference path

Immutable inference request

Bind source identity, read-only RGBA, model identity, and preprocessing version. A dedicated one-thread pool runs the adapter without blocking UI rendering.

Latest-source wins

The inference scheduler coalesces requests, supports cancellation, and rejects a completed probability map if its source identity is no longer current.

Derived mask

Turn probabilities into a master mask using target, sensitivity, inversion, expansion, and feather. Derived masks are cached by complete mask identity.

UI states

Disabled/unavailable, detecting with progress, ready, cancelled, or explicit error. Missing assets fail closed; a source change clears stale authority.

When active, masking is supported for still preview and raster export. SVG, batch, animation export, and video export are visibly disabled/guarded.
05Snapshot & schedule the previewDebounce → immutable request → one worker + one freshest trailing request＋
control changed→ 20 msDRAG ≤ min(640, policy cap)→ 160 ms idleSETTLE ≤ policy cap

Frozen request

Capture settings, source reference/identity, logical size, target cap, color engine, effect stack, mask context, overlay flag, kind, and generation. Workers never reread mutable controls.

Priority

Within one generation: DRAG < SETTLE/ZOOM < FULL; ties favor the freshest. Newer generations always win.

Coalescing

At most one preview render runs. While busy, state changes replace a single pending trailing request; obsolete work cancels safely at stage boundaries.

Quality variants

Full Quality Preview is uncapped. Optional zoom refinement requests a higher resolution bucket only when needed and never exceeds the configured ceiling/source size.

The viewport’s scene geometry stays source-logical even when the actual pixmap is capped, so replacing a preview does not reset the user’s pan/zoom.
06Execute the frozen render pipelineExact fixed stage order with bounded staged cache and cancellation boundaries＋
contrast→midtones→highlights→blur/sharpen→dither→color→saturation→effects→invert

Tonal stages

Convert base to float32 and apply contrast → midtones → highlights through call-private scratch, then blur/sharpen. Cache this L1 result by source and adjustment signature.

Dither internals

Nearest-downscale by scale; optionally subtract the resized temporal field; apply deterministic creative transforms; invoke the selected registry kernel; promote binary kernels to N tones when depth > 2; undo transforms/mix; nearest-upscale.

Color & finish

Map grayscale through the frozen ColorEngine/palette mode (or broadcast gray to RGB), apply saturation to uint8, run the ordered EffectStack, then apply invert last.

Cache & safety

Bounded editor-owned cache reuses valid L1–L5 intermediates. Temporal fields bypass dither caching. Context is snapshotted once. Cancellation occurs only between stages; exceptions reach a terminal handler.

Core invariant: this nine-stage order never changes. Exact exports use the same pipeline without the screen-preview resolution cap.
07Apply the mask wrapper, when activeRender whole branch first, then composite—or bake white/black before dithering＋

Disabled branch

Call the historical renderer directly. No source hashing, derivation, resize, composite, or mask allocation occurs.

Outer-composite branch

Render the complete nine-stage branch, resize master mask/source RGBA to result size, then combine the processed target with Original, Transparent, White, or Black outside pixels.

Baked-fill branch

For White/Black + “Bake fill into dither,” feather-blend the fill into the grayscale base before proxy scaling and stage 1. Render uncached through the pipeline; skip the outer composite so dither/effects texture the fill.

Overlay & caching

Composite results cache by rendered identity + geometry + mask identity + outside mode + algorithm version. Optional editor-only overlay visualizes the derived mask after compositing.

08Deliver only the current resultNumPy RGB → owned QImage → source-logical viewport; stale work never paints＋

Success

Convert the uint8 NumPy output to a safely owned QImage/QPixmap. Paint only if its generation is current; fit once after a new source, otherwise preserve zoom and pan.

Stale result

Drop it without painting. The scheduler promotes the single pending freshest request, if one exists.

Cancelled result

Treat it as expected obsolescence, release the busy state, and launch the trailing request.

Failure

Do not paint the failed result, but always deliver terminal cleanup so the scheduler cannot remain wedged; then continue with any pending request.

09Choose an output pathInteractive display, exact still export, vector, batch, animation, or video＋
APreviewScreen-only capped result＋

The viewport displays the latest capped or full-quality result. It is not an export authority: ordinary exports rerender exactly from the source and current settings.

BPNG / JPGExact current still render＋

Build an export pipeline from current frozen color/effect context, render at full source resolution, apply Smart Mask if active, then save canonical uint8 raster. JPEG composites transparency on white.

CSVGBinary raster runs → vector shapes＋

Threshold a full-resolution grayscale result, merge horizontal runs, and serialize SVG. Active scoped Smart Mask blocks this path because its raster composite semantics are unsupported.

DBatch folderRepeat exact pipeline per image＋

Decode supported files, resize consistently against the reference size, render through the same core settings/pipeline, save results, and report processed/skipped counts. Scoped Smart Mask blocks batch.

ETemporal animationTimeline settings + threshold fields＋

For each frame, interpolate keyframed settings with easing, generate one of nine deterministic temporal fields, pass it into dither thresholding, and render. Scrub/playback is async, capped, and latest-wins; export renders exact frames then ffmpeg encodes MP4. Scoped Smart Mask blocks export.

FImported videoExtract → per-frame dither → encode/mux＋

ffmpeg extracts numbered frames; preview playback shows capped frames. Export workers dither every frame with current settings, encode video, and preserve original audio when present by extract/mux. Worker references live until terminal delivery. Scoped Smart Mask blocks export.

Presets are a state path, not a rendered-media path: save/load locally, or import/export YAML-compatible preset data for reuse.
